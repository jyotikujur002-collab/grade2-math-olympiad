# 第 7 讲 一笔画：小七走迷宫不抬笔

| 项目 | 内容 |
| --- | --- |
| 周次 | 第 7 周 |
| 单元 | 第二单元 规律与图形 |
| 本周目标 | 会数每个点连着几条线，用「单数点」判断能不能一笔画 |
| 达标标准 | 能在图上标出每个点的线数并给出判断，5 题做对 4 题。 |
| 建议安排 | 每周 2 次，每次 20 分钟；第 1 次看讲解与例题，第 2 次做练习与打卡 |

## 1. 情境引入（讲给孩子听）

森林地上画着一条亮线，规则是笔不离纸、线不重复。小七试了三次都失败，阿算说：先别急着画，数数每个路口连着几条线。

## 2. 方法口诀

> **单数点 0 个或 2 个，才能一笔画**

1. 把交点当成路口，数一数每个路口连出几条线。
2. 连出单数条线的路口叫「单数点」。
3. 单数点有 0 个或 2 个：能一笔画；有 4 个及以上：不能。

## 3. 例题（家长带着读，先让孩子说思路）

**例 1** 三角形能一笔画吗？

- 每个顶点都连着 2 条线，是双数点
- 单数点 0 个，可以一笔画

**答：能**

**例 2** 正方形加一条对角线，能一笔画吗？

- 对角线两端的点各连 3 条线，是单数点
- 另外两个点各连 2 条线，单数点正好 2 个

**答：能，从其中一个单数点出发**

**例 3** 「田」字能一笔画吗？

- 四条边中点各连 3 条线
- 单数点有 4 个

**答：不能**

## 4. 课堂练习（5 题，独立完成）

| # | 题目 | 选项 | 正确答案 | 解析 |
| --- | --- | --- | --- | --- |
| 1 | 三角形的每个顶点连着几条线？ | 1 / 2 / 3 / 4 | 2 | 每个顶点连 2 条 |
| 2 | 正方形加一条对角线，有几个点连着 3 条线？ | 0 / 1 / 2 / 4 | 2 | 对角线两端的 2 个点 |
| 3 | 一个图形有 4 个点连着单数条线，能一笔画吗？ | 能 / 不能 / 看颜色 / 都要试 | 不能 | 单数点超过 2 个就不能 |
| 4 | 一个圆能一笔画吗？ | 能 / 不能 / 要两支笔 / 不确定 | 能 | 没有单数点，从任意点出发回到原点 |
| 5 | 正方形（不加对角线）每个顶点连着几条线？ | 1 / 2 / 3 / 4 | 2 | 每个顶点连 2 条 |

## 5. 易错提醒

只凭「看起来简单」就下结论。一定要把每个路口的线数写在旁边，数完再判断。

## 6. 家长陪伴提示（只提问，不讲公式）

1. 每个路口连着几条线？在旁边写下来。
2. 单数点一共几个？
3. 如果从单数点出发，能走回哪里？
