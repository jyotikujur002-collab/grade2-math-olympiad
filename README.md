# 二年级奥数·数学森林闯关

面向 小学二年级（7-8 岁），已掌握 100 以内加减法与表内乘除法。16 周、16 讲，每周 2 次、每次 20 分钟。每讲包含：教案、卡通讲解（网页动画课堂，可叠加 MP4 短片）、3 道例题、5 道练习与解析、达标标准、进度记录与家长反馈。

**起始日期：待填。** 下表用相对周次，不预设日历日期；确定开课日期后填入 `progress/学习计划与进度表.csv` 的「起始日期」列。

## 3. 达标、积分与徽章

| 情况 | 处理 |
| --- | --- |
| 达标 | 5 道练习做对 4 道及以上，且能用自己的话说出本讲方法 → 达标 |
| 做对 3 题 | 做对 3 道 → 订正错题，隔一天重做错题 → 达标 |
| 做对 ≤2 题 | 做对 2 道及以下 → 重看动画讲解与例题，本讲顺延一周，不进入新讲 |

积分规则：

- 看完卡通讲解 +2 分
- 看懂 3 道例题 +2 分
- 练习每做对 1 题 +2 分
- 课后自评三星 +3 分
- 家长填写一次周反馈 +5 分

徽章：

- 计算小能手：完成第 1-4 讲且全部达标
- 火眼金睛：完成第 5-8 讲且全部达标
- 解题侦探：完成第 9-12 讲且全部达标
- 坚持之星：完成第 13-16 讲且全部达标

> 连续 2 周未达标，不要往下推进；把该讲的例题重讲一遍，并换一组同类型口头题，确认方法真的会用了再继续。

## 4. 进度管理（三处同步，任选其一也能跑通）

1. **网页自动**：练习判分、打卡、积分、错题本、周反馈全部存在浏览器 `localStorage`，首页「导出进度」生成 JSON，换设备时「导入进度」还原。
2. **表格人工**：`progress/学习计划与进度表.csv` 每讲一行，填完成状态、得分、星级、错题数、达标状态；`progress/家长反馈记录.csv` 每周一行。
3. **GitHub 协作**：用 `.github/ISSUE_TEMPLATE/` 里的三类模板开 Issue；建议建一个 Projects 看板，列设为 `待学 / 学习中 / 已达标 / 需复学`，每讲一张卡片，讲完拖动。

进度状态取值统一为：`待学`、`学习中`、`已达标`、`需复学`。

## 5. 反馈机制

| 层级 | 谁填 | 什么时候 | 内容 |
| --- | --- | --- | --- |
| 课后自评 | 孩子 | 每讲练习后 | 三星：我懂了 / 有点难 / 没听懂；点星星即记录 |
| 错题本 | 网页自动 + 孩子订正 | 每讲练习后 | 错题干、正确答案、是否已订正 |
| 家长周反馈 | 家长 | 每周末 | 卡在哪一题、最有成就感的一题、下周调整 |
| 单元复盘 | 家长 | 第 4/8/12/16 周末 | 4 讲达标情况、是否需要补讲、徽章是否解锁 |
| 求助 Issue | 家长 | 随时 | 贴错题、孩子当时的想法，便于针对性讲解 |

反馈如何改变计划：

- 家长反馈「卡在某一类题」→ 下一周第 1 次课用 5 分钟重看该讲动画课堂，不新增内容。
- 连续 3 周全部达标且自评三星 → 可把每周 2 次压缩为 1 次，腾出时间做本讲的「变式题」（把例题数字换掉重做）。
- 自评连续 2 次「没听懂」→ 暂停新讲，回到该单元第 1 讲重学。

## 6. 卡通讲解说明

- **动画课堂**：网页内置 SVG 卡通角色（小狸阿算、方块小七），每讲 4-5 帧逐句讲解，可播放 / 暂停 / 上一句 / 重播。算式与讲解词由课程数据驱动，内容可控。
- **MP4 短片**：本次视频生成调用未获授权，`videos/` 下暂无 mp4 文件。网页会按 `unitN-opening.mp4` 自动尝试读取，找不到即回退到动画课堂，学习流程不受影响；分镜脚本与生成提示词已齐备，补齐文件后即可播放。
- **分镜脚本**：16 讲全部分镜写在各讲教案第 8 节，并汇总在 `videos/README.md`，可按同一模板继续生成其余讲次的 MP4。
- 设计原则：AI 生成的视频画面不承载具体算式与数字，避免出现错字错数；知识点、算式、解析一律以教案和网页动画课堂为准。
